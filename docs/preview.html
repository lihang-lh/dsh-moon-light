dsh-mood-light · 氛围灯预览（v0.4.0）

本页是零依赖单文件预览，复刻 client.js 的渲染逻辑，不需要宿主即可查看效果。
v0.4 要点：状态由三态扩为五态（运行中 / 已完成 / 待审批 / 计划待审 / 待回答）； 新增环境光、噪点质感、完成扫光与双层 crossfade 平滑过渡；深浅色自动适配； glowWobble 默认由 1 改为 0（不再默认对全屏施加 SVG 滤镜，属性能修复）； 新增顶部触发带 + 悬浮胶囊与输入框下 36px 状态条两种交互。
右侧面板可实时调参；把鼠标移到页面最顶部 10px 内即可唤出真实胶囊（移开 220ms 后淡出）， 面板中的「切换到浅色 / 深色」按钮可在两种主题间切换，便于对比截图。
